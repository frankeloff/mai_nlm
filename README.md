# Репозиторий для лабораторных работ по курсу «Современный NLP и большие языковые модели» (МАИ)

## Лабораторная работа 1: Агент-художник

Вымышленная художественная школа «Академия цифрового отчуждения» на тему «Одиночество в эпоху алгоритмов»: куратор пишет манифест и брифы, художник спорит с критиком (мультимодальная модель реально смотрит на холсты), после каждой принятой картины школа усваивает новый принцип — и следующая картина ломает один старый (догмат «наследуй всё — сломай один»). Галерея школы — на GitHub Pages (корневой `index.html`). Подробности, запуск и результаты — в [`lab1/README.md`](lab1/README.md) и [`lab1/REPORT.md`](lab1/REPORT.md).

## Лабораторная работа 2: Агентский театр

Многоагентная система симуляции пьесы: три LLM трёх производителей спорят, кто из них «настоящий актёр». Подробности, запуск и результаты — в [`lab2/README.md`](lab2/README.md) и [`lab2/REPORT.md`](lab2/REPORT.md).
