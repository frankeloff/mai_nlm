# Один клиент LLM поверх Responses API для всех трёх семейств моделей

Три персонажа играются моделями трёх разных производителей (YandexGPT, Qwen, DeepSeek), доступных в одном каталоге AI Studio. Мы вызываем их всех через единый OpenAI-совместимый Responses API (`https://ai.api.cloud.yandex.net/v1`) с URI вида `gpt://{folder_id}/{model}`, а не через разные SDK-пути.

## Considered Options

- **`yandex-ai-studio-sdk` для всего**: SDK курса; но тесты показали, что у Qwen и DeepSeek формат ответа отличается (поле `summary` с размышлениями вместо `content`), и нормализацию всё равно приходится делать руками.
- **Прямой OpenAI-клиент на Responses API** (принято): один тонкий слой `LLMClient` с парсингом/нормализацией вывода и fallback-логикой на оба формата ответа; инструменты (file search, web search) — через те же `tools` параметры API.

## Consequences

- Ответы Qwen/DeepSeek могут содержать «размышления» — клиент обязан их отделять от текста реплики.
- Замена модели-актёра = замена одной строки URI в конфиге персонажа.
