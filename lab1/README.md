# Агент-художник

Лабораторная работа: многоагентная система для рисования концептуальных картин на заданную тему — **вымышленная художественная школа**. Единственный человеческий вход — заданная тема («Одиночество в эпоху алгоритмов»); всё остальное — название школы, манифест, брифы, промпты, критика — порождается самими агентами:

- **Куратор** (`yandexgpt-5.1`) — открывает школу: манифест из 5 принципов, бриф на каждую картину, поправка после каждой принятой (догмат «наследуй всё — сломай один»);
- **Художник** (`aliceai-llm`) — темпераментный бунтарь: по брифу пишет промпт для YandexART (реплика на русском + финальный промпт на английском);
- **Критик** (`qwen3.6-35b-a3b`, единственная мультимодальная модель каталога) — реально *смотрит* на готовый холст и выносит структурированный вердикт (оценки 1–10, замечания, accept/revise);
- холсты — **YandexART** (`aliceai-image-art-3.0`) через Image Generation API.

Результат: коллекция из 5 картин с полными протоколами диалогов и эволюционировавшим манифестом.

## Запуск

```
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name artist --display-name "artist (lab1)"

cp .env.sample .env          # вписать folder_id и api_key из Yandex AI Studio

python scripts/build_notebook.py    # сборка Agent_Artist.ipynb из ячеек
jupyter lab Agent_Artist.ipynb      # и выполнить все ячейки сверху вниз
# или headless-прогон:
python scripts/run_notebook.py
```

Параметры прогона переопределяются переменными окружения: `ARTIST_THEME` (тема, по умолчанию «Одиночество в эпоху алгоритмов»), `ARTIST_PAINTINGS` (картин, по умолчанию 5), `ARTIST_MAX_ITER` (итераций VLM-контура на картину, по умолчанию 3).

Сайт галереи собирается из результатов прогона: `python scripts/build_site.py` → `site/index.html` (файл копируется в корень репозитория, публикация — GitHub Pages из ветки main).

Если Куратор «ослышался» в архиве (служебное название картины, своя роль вместо роли картины): `python scripts/repair_collection.py` — просит Куратора исправить собственный архив и перерендеривает `manifest.md` / `dialogue.md` из `collection.json`.

## Артефакты

- `Agent_Artist.ipynb` — вся система с пояснениями по принципам реализации;
- `output/paintings/` — все холсты по итерациям (`pN_iM.png`) и финалы (`pN_final.png`);
- `output/manifest.md` — летопись манифеста: первая редакция, поправки, финал, эпилог;
- `output/dialogue.md` — полный протокол диалогов агентов;
- `output/collection.json` — машиночитаемый дамп прогона (основа сайта);
- `site/index.html` — галерея «история школы» для GitHub Pages;
- `REPORT.md` — отчёт по шаблону задания;
- `GLOSSARY.md` — терминология проекта;
- `docs/adr/` — принятые архитектурные решения.
