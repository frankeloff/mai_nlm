# Распределение моделей по ролям

Роли закреплены за моделями одного каталога Yandex AI Studio (OpenAI-совместимый шлюз `ai.api.cloud.yandex.net/v1`):

- **Куратор — `yandexgpt-5.1`**: проверенный «драматург» (эту же роль модель играла в lab2), держит длинный контекст школы и пишет манифест/брифы/поправки структурированным выводом;
- **Художник — `aliceai-llm`**: непроверенная в боях лабораторных модель, выбранная ради третьего «голоса» третьего производителя (перенос урока lab2: выбор модели — тоже художественное решение) и творческой репутации Alice; запасной план при слабых промптах — `deepseek-v4.1-flash`;
- **Критик — `qwen3.6-35b-a3b`**: безальтернативно — единственная мультимодальная модель каталога (принимает `input_image` в Responses API), т.е. только она способна «реально смотреть» на картины;
- **картины — `aliceai-image-art-3.0`** (YandexART) через `client.images.generate`.

**Consequences**: у каждой роли свой темперамент не только из промпта, но и из «природы» модели; Критик и Художник не могут поменяться моделями без потери зрения/голоса соответственно.
