# Механика эволюции школы: «наследуй всё — сломай один»

Коллекция должна показывать эволюцию от картины к картине, а не набор независимых иллюстраций. Решили ввести формальную механику: после каждой принятой картины Куратор пишет **поправку** к манифесту, которая добавляет один новый принцип и назначает единственный принцип, который **следующая** картина обязана нарушить; остальные принципы обязательны. Картина №1 — ортодоксия: все принципы соблюдаются буквально.

**Considered Options**:
- свободная эволюция (весь прошлый контекст просто в промпте) — не гарантирует видимого дрейфа стиля и не даёт читаемого сюжета для сайта и отчёта;
- ручное задание стилей для каждой картины — убивает агентность: человек, а не система, делает художественные решения.

**Consequences**: механика делает диалоги содержательными сами по себе (Художник оправдывается за нарушение, Критик сверяется с принципами), а эволюция манифеста становится отдельным артефактом — «летописью школы».
