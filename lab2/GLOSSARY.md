# Агентский театр

Лабораторная работа: многоагентная система на Yandex AI Studio, симулирующая пьесу — три LLM-персонажа разных семейств спорят «кто из них настоящий», оркестрируемые невидимыми агентами.

## Язык проекта

### Агенты (за кадром)

**Драматург**:
LLM-агент, который по теме-семени заранее пишет макроплан пьесы: название, персонажей, действия со списками сцен-майлстоунов и финал.
_Avoid_: планировщик, сценарист (в смысле человека)

**Режиссёр**:
LLM-агент, управляющий ходом действия: после каждой реплики решает, кто говорит следующим (структурированный выбор), пишет ремарку к следующей реплике и объявляет акт завершённым, когда покрыты майлстоуны.
_Avoid_: оркестратор, диспетчер, классификатор реплик

**Труппа**:
Три LLM-актёра — по одному на модель: Артист, Прагматик, Простак. Обращение к каждому — вызов его модели с его системным промптом-маской.

### Персонажи (на сцене)

**Артист**:
Персонаж-интеллектуал; играет модель `yandexgpt-5.1`. Говорит вычурно, цитирует классиков через поиск по корпусу пьес.
_Avoid_: Яндекс (имя модели — не имя персонажа)

**Прагматик**:
Персонаж-рационалист; играет модель `qwen3.6-35b-a3b`. Сухой, требует фактов, проверяет их веб-поиском.
_Avoid_: Куэн, Qwen

**Простак**:
Персонаж-простодушный; играет модель `deepseek-v4.1-flash`. Короткие наивные реплики; его простота — драматургический двигатель спора.
_Avoid_: Дип, DeepSeek

### Структура пьесы

**Акт**:
Часть пьесы, раскрывающая один пункт макроплана Драматурга; завершается решением Режиссёра при покрытии майлстоунов или жёстким лимитом реплик (страховка).

**Сцена-майлстоун**:
Атомарный пункт плана внутри акта, который Режиссёр должен отметить покрытым, прежде чем завершить акт.
_Avoid_: этап, беат

**Реплика**:
Единица диалога: одна фраза одного персонажа, сгенерированная его моделью в ответ на историю сцены.

**Ремарка**:
Закадровый комментарий от Режиссёра: описание сцены, действие актёра (*проходит к столу*) или уточнение интонации (*шёпотом*).
_Avoid_: комментарий, annotation

**Тема-семя**:
Одно предложение, фиксирующее замысел пьесы; единственный человеческий вход в систему помимо настроек.
_Avoid_: промпт пользователя

### Материалы

**Корпус пьес**:
Коллекция текстов русских пьес (public domain), загруженная в Vector Store для файлового поиска Артиста.

**Радиоспектакль**:
Итоговый артефакт: текст пьесы (`play.md`) + аудиодорожка, где каждая реплика синтезирована голосом персонажа (SpeechKit), склеенная в файл по действиям.
_Avoid_: подкаст, аудиокнига
